# 2026-09-25：单节点八卡 decode-only，双四卡 TP2×DP2 对照

## 结论与适用范围

在 `gpu-6000d-45` 八卡、**全局** C128、单条真实 16K 前缀/1024 输出的 vLLM 0.30.0 quick 对照中，两个独立四卡 TP2×DP2 服务（A）的整机 output tok/s 为 **4874.18±139.37**，一个八卡 TP2×DP4 服务（B）为 **4241.97±104.06**，一个八卡 TP4×DP2 服务（C）为 **3919.88±24.64**；均为固定三轮的均值±样本标准差。A 比 B 高 14.90%，比 C 高 24.35%，B 比 C 高 8.22%。因此这次 decode-only **TP2×DP2 双四卡部署胜出**，为后续 24 卡 4P2D 优先采用双四卡 D 提供方向性证据，不是单个四卡服务与八卡服务的等 GPU 对比，也不证明真实 PD 端到端或其他并发档位的排名。

A/B 的正式窗口仍出现已知 JIT 匹配，A 吞吐存在非单调漂移；B 在后续独立启动批次测完。A/B 的差异还同时涉及服务边界、DP 路由和 EP 组范围，不能全部归因于跨 NUMA 通信。历史不同镜像/数据的八卡实验仅作拓扑线索，不与本次数值排名。这里的前缀缓存仍需每请求**本地计算约 256 输入 tokens**，不是零 prefill。

## 数据、客户端与复现入口

原始输入来自本机历史[前缀 JSONL](../../../experiments/dsv4-v030-pd-20260924/deployments/G1M/data/input.jsonl)，SHA256 `025246b18d8ba7e1bc4d98c1a20b32b570860bb06a0baf0cea4ae97403d982e7`；单条输入经同一 tokenizer 核验为 16384 tokens。三组均复制**同一条**前缀，temperature=0、`ignore_eos`、无限到达率、每请求 1024 输出。该输入不等于 24 卡 PD 实验使用的 1024 条独立 GovReport 语义输入，**不能直接比较两批绝对 tok/s**。

一次全局 256 条完整请求预热，随后固定三轮各 **全局 512 条**正式请求。A 由同步客户端同时驱动两个服务：每边 C64、每轮 256 条；B/C 各由单客户端 C128 驱动、每轮 512 条。全部使用固定镜像的官方 benchmark、相同同步入口与 `/v1/completions`，**并没有统一反向代理路径**；服务数量和客户端数有别。A 的整机吞吐采用两侧完成输出总 tokens 除以两个计时窗口的**并集时长**，没有直接把两边各自 tok/s 相加。客户端实测 argv 可在本机 [A0](../../../experiments/dsv4-decode-8gpu-20260925/results/run-03/A/round-1/replica-0/command.json)、[A1](../../../experiments/dsv4-decode-8gpu-20260925/results/run-03/A/round-1/replica-1/command.json)、[B](../../../experiments/dsv4-decode-8gpu-20260925/results/run-04/B/round-1/replica-0/command.json)、[C](../../../experiments/dsv4-decode-8gpu-20260925/results/run-03/C/round-1/replica-0/command.json) 中核对。

每个预热/正式窗口均先确认 idle、reset prefix cache、用相同输入 prime，再逐 DP 引擎验证命中。B 的原生 DP4 路由在早期 prime 没覆盖四引擎，最终只在 **prime** 时逐 rank 加 `X-data-parallel-rank`；预热/正式请求仍走原生动态路由。服务初启的少量单 token seed 用于初始化 v0.30 惰性发布的 gauges，随后 reset，不并入完整预热/正式窗口。每个服务启动上限 2100 s、阶段 900 s、单部署测量 4200 s、整个尝试 20000 s，零性能重试；失败尝试保留。完整本地编排的[原始脚本](../../../experiments/dsv4-decode-8gpu-20260925/scripts/run.py)和[固定预算](../../../experiments/dsv4-decode-8gpu-20260925/results/budget.json)属于忽略的 `experiments/`，**并非本仓库检出即可运行的通用多服务 campaign**；根 README 归档的是单个已启动服务的 decode-only 客户端使用方法。异机复现多服务时必须先移植冻结配置、前缀数据、补丁/缓存准备和同步编排，并重做 GPU/NUMA/镜像/端口预检，不能只执行这些 Docker argv 就声称复现了结果。
